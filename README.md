# Dr. Alan Smith - Personal Site & Live Classroom

Personal blog and fully-online classroom for Dr. Alan Smith, Senior Lecturer in Computer Science, teaching live from Kyoto during a one-year residency abroad.

- Live classroom: real video (camera, mic, screen-share, chat, whiteboard) powered by Jitsi Meet. No accounts, no backend.
- Schedule: weekly classes in Kyoto time, auto-converted to each visitor's timezone.
- Blog, About, Contact & office hours.

Single static file (index.html) - nothing to build. Deploys as-is on Vercel.
